À PROPOS DU PROJET

Un atlas, pas un aspirateur à RAM.

Unicode Atlas sépare l’interface, les styles, le code JavaScript et l’échantillon de données. Il est conçu pour GitHub Pages et fonctionne sans serveur applicatif. Pour une recherche instantanée dans la base entière, il faudra un service de recherche ou une base découpée en fichiers paginés : une page statique ne peut pas interroger un fichier SQLite distant toute seule.
